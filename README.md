# perspective-router · 思维视角路由器

> 当用户要求以特定人物的思维视角分析问题时，自动匹配最合适的视角 Skill 并路由。

9 个视角 Skill（Alexander/Meadows/Rosling/Campbell/Kelly/LKs/Taleb/Wiener/Panluan），一个路由入口。用户不需要记住哪个视角叫什么名字——描述问题，路由器匹配。

## 快速开始

```
> 帮我安装这个 skill：https://github.com/wampeeHuang/perspective-router
```

触发词：用XX的视角、XX会怎么看、换一个视角

## 设计哲学

### 路由匹配靠问题特征，不靠关键词
"这个产品有生命吗"→ Alexander。"这个系统的反馈回路在哪"→ Meadows。"做这件事的风险是什么"→ Taleb。路由规则基于问题类型和框架亲和度，不是基于"用户提到了谁的名字"。

### 视角间互斥是系统设计
当一个视角被激活时，其他视角的信息污染不进入回答。不是"综合多个角度"——是"用一个人的镜片看完整遍"。

### 路由失败时降级，不猜测
无法匹配的视角请求 → 列出可用视角 → 让用户选。不自己猜"大概是想用这个"。

## 诚实边界

- **视角覆盖 9 位思想家。** 不在列表内的人物需要 nuwa-skill 先蒸馏
- **路由是确定的规则匹配。** 复杂/混合问题可能匹配不准确
- **视角间不混合。** 如果需要多视角综合分析，需要分别调用后人工合并
